## CU 判定与当前缺陷

**R04C-CITY-REPETITION / MAJOR / CU-01、CU-04、CU-06 / O01、O02、O03、O06。** 主图右侧、顶部与第二视角中的楼群仍呈均匀六格单元阵列，巨大弯曲表面更像模块墙。城区缺少低层段、留白、塔楼簇和可阅读的分区节奏。提高采样已经使这一问题更清楚，不能继续归因于低清预览。下一次干预只改楼群组合和高度/疏密关系，保护舰体、船坞、灯光、镜头与运动参数，使用同参数控制图验证。

**R04C-SHIP-CRAFT / MAJOR / CU-03、CU-06 / O01。** 舰体可见且有艏部与舱段，但浅色楔形外壳、重复舱段和穿过轮廓的船坞线条仍显粗略。它还不是专业主资产。城市实验不同时改舰体，避免丢失因果对照。

**R04C-NEAR-CRAFT / MAJOR / CU-05 / O04。** 近景小车仍主要是箱体、底板与粗轮组，柜体分缝、维护开口、轮轴承托及接触工艺不足。不同材料的表面响应有限；不能用暗色柜体掩盖建模不足。当前不进入微装饰堆砌。

**R04C-TRANSPORT / QUESTION / CU-02 / O05。** 新回程升降图能同时看到两层平台和连接塔，不能继续机械复述旧版“上下端点都被裁掉”的结论。但上层轨道、载台与接口的完整交接仍未从这个机位得到证明；抬高船坞后的全链证据尚需独立补齐。因此不是整条运输链 FIXED。

**R04C-PARALLAX / 宏观证据有效、非全局 PASS / CU-06。** 五张静态侧移中，近处小车相对舰体和城区产生合理位移；没有出现只靠静态参考图投影的迹象。只覆盖本条短位移观察，不外推为任意机位无穿插。

**R04C-MOTION / 待读。** 写入本评审时两个连续分片尚未取回，不能根据 .blend 的关键帧、样片端点或“正在渲染”宣布完整视频完成。已新增 assemble_r04c.py 与有界拼接工作流；必须验证两段各 96 帧、同一场景版本、合并后 192 帧/8 秒、PTS 连续和源 PNG 色彩一致。该检验也不能单独证明无视觉闪烁。
